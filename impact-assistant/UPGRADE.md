# Обновление существующего стенда

Для новой установки используйте [обычный запуск](START.md). Эта одноразовая процедура
сохраняет действующие учётные данные и тома прежней поставки. Нужен Python 3 на хосте.


До остановки старого стенда скачайте новый образ и
[upgrade_credentials.py](upgrade_credentials.py). Выполните:

```console
python3 upgrade_credentials.py --image ghcr.io/avkuzmin/impact-assistant:sha-60f4ed75c82ec8b6fd51787f63ef9c8a33f68027
```

В команде закреплён образ этой поставки. Инструмент
находит только работающие контейнеры проекта `impact-cloud-poc`, читает их старую
конфигурацию без вывода значений и переносит технические пароли в том инициализации.
Для другого имени проекта явно добавьте `--project NAME`. Он не читает ключ Yandex,
не останавливает сервисы и не меняет пароли. Повтор с отличающимися значениями
отклоняется. Сделайте резервную копию томов перед обновлением.

Затем выполните `docker compose down` без `-v`, замените Compose новым и выполните
`docker compose up -d`. initialize сохранит импортированные пароли; bootstrap
перенесёт их в Vault. Старые отчёты и активная версия сохраняются. Для новой установки
импорт и Python не нужны. При старом томе без импорта initialize завершается с
ошибкой, а не записывает несовместимые новые пароли.


[Назад к запуску](START.md).
