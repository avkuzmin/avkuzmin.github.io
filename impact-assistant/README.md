# Impact Assistant

[Открыть презентацию](https://avkuzmin.github.io/impact-assistant/)

Основная структура: **проблема → решение → доказательство**. 26 слайдов: основной рассказ 01–12 на пять минут, вспомогательные материалы 13–26.

- 01–02: проблема архитектора.
- 03–09: решение и архитектура; C1/C2/оба C3/развёртывание стоят рядом на 04–08.
- 10–12: новый анализ через UI, его результат и границы доказательства.

Матрица сравнения правил и LLM находится на вспомогательном слайде 22. Стрелки и пробел переключают слайды. «Короткий показ» ограничивает навигацию основными двенадцатью слайдами; «Слайды» открывает оглавление.

## Видео на слайде 10

Нажмите «▶ Видео · 60 с». Это запись настоящего нового анализа PriceChanged: вопрос обычным языком → выбор объекта → уточнение v2 → подтверждение → новая задача → отчёт и основание в исходнике. Ролик сокращён до 60 секунд: ожидания занимают около 6 секунд вместо 21 и ускорены до ×16 с видимой подписью, паузы между действиями сокращены. Запись без звука, работает из папки `media/` без обращения к моделям.

Модель действительно вызвана при исходном запуске; её ответ отклонён проверкой. Этот исход показан в интерфейсе, формальная часть отчёта сохранена. Ролик подтверждает работоспособность цепочки и демонстрирует ограничение качества, а не гарантированную правильность LLM.

Закрыть видео можно кнопкой или Escape. Пока видео открыто, стрелки и пробел не переключают слайды. Презентация работает без сервера приложения и внешних зависимостей. Схемы MVP отделены от фактически работающего облачного POC.

## Соответствие материалам проекта

Редакция от 15.09.2026: 29 принятых ADR, S3 и Vault в корпоративном контуре MVP.
[Идентификатор поставки](release.json) связывает презентацию с опубликованным
[коммитом приложения bc18068](https://github.com/avkuzmin/otus-ai-architect/tree/bc180680bcf5654b7fe35db437e7b58baaad8af2).
Для запуска без клонирования нужны поставочный Compose, приватный YAML и Docker Compose. Образ GHCR публичный, токен не нужен. [Инструкция запуска](https://github.com/avkuzmin/otus-ai-architect/blob/bc180680bcf5654b7fe35db437e7b58baaad8af2/docs/development/COMPOSE-POC.md).
Образ опубликован публично; digest закреплён в Compose. Контейнер api объединяет
HTTP и исполнитель анализа под общим управлением процессов; operator отдельно.
Проверены анонимное скачивание, реальный облачный анализ через API, повтор, отмена,
доступ, отказ исполнителя и сохранность отчёта после перезапуска. Проверки UI и
полный регрессионный прогон в этом этапе не запускались. Слайды 05/08/18 и схемы
репозитория синхронизированы; MVP и реализованный POC обозначены раздельно.
Модельный текст содержит смысловые ограничения; статус findings не доказывает
правильность каждого утверждения. Запись UI сохранена как историческое доказательство
предыдущего запуска и не выдаётся за запись нового контейнера.

## Запуск демонстрации

[Короткая инструкция](START.md) · [Скачать Compose](https://avkuzmin.github.io/impact-assistant/compose.yaml).
Положите рядом выданный автором `secrets.yaml` и выполните `docker compose up -d`.

Последовательности MVP: [задание подготовки и опрос UI](https://avkuzmin.github.io/impact-assistant/#23),
[выбор и уточнение](https://avkuzmin.github.io/impact-assistant/#24),
[выполнение анализа](https://avkuzmin.github.io/impact-assistant/#25),
[внутренний поиск и намерение](https://avkuzmin.github.io/impact-assistant/#26).
Поиск по имени независим от ветки «эмбеддинг → векторный поиск». Модели отвечают
через корпоративный GPUStack. Это целевой порядок MVP, а не утверждение о
параллельности текущего POC. Основной маршрут 01–12 / 300 секунд не изменён.
