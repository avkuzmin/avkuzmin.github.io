# Impact Assistant

Презентация дипломного проекта OTUS AI Architect.

[Открыть презентацию](https://avkuzmin.github.io/impact-assistant/)

21 слайд. Основной рассказ: 01–12, 5 минут. Архитектура: 04–08. Вспомогательные материалы: 13–21.

Последовательность: задача пользователя, сравнение правил и LLM, архитектура и причины решений, демонстрация PriceChanged, разбор отчёта и итог POC.

Стрелки и пробел переключают слайды. Кнопка «Короткий показ» включает основной маршрут, «Слайды» открывает оглавление. Каждый слайд доступен по ссылке с номером, например `#9`.

Статический просмотрщик работает без сервера приложения и внешних зависимостей. Для демонстрации приложения используется локальный POC.

Во вспомогательных слайдах: критерии качества, жизненный цикл, безопасность, наблюдаемость, время и стоимость облачной серии, содержательная оценка ответов модели и текущий стек Compose POC.

DFD целевого MVP: слайд 20 — подготовка знаний, слайд 21 — подготовка изменения и анализ.

## Видео демонстрации

На слайде 10 нажмите «▶ Видео · 75 с». Видео открывается внутри презентации с управлением воспроизведением; закрывается кнопкой или Escape. Это сохранённые результаты четырёх вызовов API, без звука, а не запись работы интерфейса. Ролик включён в папку `media/` и не обращается к облачным моделям. Используйте его вместо живой демонстрации, чтобы сохранить общий пятиминутный тайминг.
