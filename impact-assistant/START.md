# Запуск Impact Assistant

Нужны установленный и запущенный Docker Desktop с Compose и интернет.
Текущий образ — ARM64; проверен на Mac с Apple Silicon.

## Первый запуск

1. Скачайте [compose.yaml](https://avkuzmin.github.io/impact-assistant/compose.yaml).
2. Положите рядом полученный от автора `secrets.yaml`. Файл уже заполнен — редактировать его не нужно.
3. Откройте терминал в этой папке и выполните:

```console
docker compose up -d
```

Docker скачает образы и подготовит данные. Первый запуск занимает несколько минут.
После подготовки откройте **http://localhost:8191/** и войдите:
**`analyst` / `poc-demo`**.

Не нужны `.env`, GitHub-токен, клонирование репозитория, Python или отдельная сборка.
Если запускаете из другой папки, укажите путь к Compose:

```console
docker compose -f "/полный/путь/impact/compose.yaml" up -d
```

`secrets.yaml` ищется рядом с Compose, а не в текущей папке терминала.

## Что попробовать

Нажмите «Новый анализ», введите один из вопросов, уточните объект и целевую версию,
подтвердите изменение. Дождитесь завершения задачи в списке и откройте отчёт.

| Вопрос | Ожидаемый смысл результата правил |
|---|---|
| Можно ли отключать ProductChanged v1 и перейти на v2? | Есть использование v1 и неясная версия: нужны миграция и уточнение. |
| Кого надо перевести с DeliveryChanged v1 на v2? | Найдено приложение на v1, которое нужно перевести. |
| Можно ли отключать v1 события об изменении цены товара? | У PriceChanged найдена подписка на v2. Это не доказывает, что все приложения уже переведены. |
| Можно ли отключать WarehouseChanged v1 и перейти на v2? | Подтверждённых сведений о потребителях недостаточно. |

Модельный вывод показан отдельно и может содержать ошибки. Повторное открытие отчёта
не запускает анализ заново. Для подготовки знаний войдите как `operator` / `poc-demo`.

## Перезапуск и остановка

Остановить, сохранив данные:

```console
docker compose down
```

Запустить снова:

```console
docker compose up -d
```

Обе команды по очереди также нужны через сутки работы или после замены `secrets.yaml`.
Не добавляйте `-v` к остановке: эта опция удаляет данные и отчёты.

## Если страница не открывается

```console
docker compose ps -a
docker compose logs --tail 50 prepare api worker operator bootstrap
```

Если `prepare` ещё работает, дождитесь подготовки. Норма после запуска:
`initialize`, `migrate`, `bootstrap`, `prepare` — `Exited (0)`;
`api` — `healthy`, `worker` и `operator` — работают.
[Подробная диагностика и разработка](https://github.com/avkuzmin/otus-ai-architect/blob/main/docs/development/COMPOSE-OPERATIONS.md#если-запуск-не-завершился).

## Условия демонстрации

Храните `secrets.yaml` приватно. Подготовка данных и новые анализы используют платные
модели Yandex Cloud. Модель `gpt-oss-20b` заявлена доступной до **30 октября 2026 года**;
после этой даты потребуется проверенная замена. Стенд предназначен для локального запуска.
[Передача ключа](https://github.com/avkuzmin/otus-ai-architect/blob/main/docs/development/SECRET-DELIVERY.md) · [Презентация и запись демонстрации](https://avkuzmin.github.io/impact-assistant/).
